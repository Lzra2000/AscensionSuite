Scope (this preview)

  • Loadout = named set of CA entries (Ability / Talent) with resolved ids, names, icons
  • Save Build snapshots current Wishlist (+ optional Known marks)
  • Load replaces Suite Wishlist from that build
  • Apply = Load + Push to Desired (Wildcard), with refuse reasons in status
  • Export / Import shareable text blob (Suite format, not AscensionCrafter ACE)
Not in v1: DBC dump, combat-log session capture, Hero Architect import, gear/stats theorycraft — those stay AscensionCrafter’s job. Suite stays on Rapid Desired.
Screenshot bug addressed in the same release: Wishlist Push used raw spell ids that Ascension refused — Loadouts + Push will store/resolve the real (entryId, entryType) pair first.
